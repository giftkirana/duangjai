พบบทสนทนาหลายคน เลือกเสียงให้แต่ละคน (ขึ้นบรรทัดด้วย ชื่อ:)

บันทึกเสียงพากย์เป็นไฟล์

  1. กดปุ่ม เริ่มอัด ด้านล่าง หน้าต่างแชร์หน้าจอจะเด้งขึ้นมา
  2. เลือกแท็บ ทั้งหน้าจอ (Entire screen) แล้วเปิด แชร์เสียงของระบบ (Share system audio)
  3. กดแชร์ เว็บจะเล่นเสียงพากย์และอัดให้อัตโนมัติ เสร็จแล้วได้ไฟล์ .wav ไปใส่ CapCut ได้เลย

ใช้ได้บน Chrome หรือ Edge ในคอมพิวเตอร์ Windows · Mac ยังไม่รองรับการอัดเสียงระบบจากเบราว์เซอร์

บนมือถือ ให้ใช้ การอัดหน้าจอ ของเครื่องแทน ได้ทั้งเสียงและไม่ต้องลงแอปเพิ่ม

  • iPhone: ปัดเปิดศูนย์ควบคุม กดปุ่มอัดหน้าจอ แล้วกลับมากด "ฟังเสียงพากย์"
  • Android: ปัดแถบด้านบน กด "บันทึกหน้าจอ" เลือกอัด เสียงสื่อ/เสียงภายใน แล้วกด "ฟังเสียงพากย์"

ใน CapCut ใช้เมนู "แยกเสียง" (Extract audio) ดึงเฉพาะเสียงจากคลิปอัดหน้าจอได้

วิธีพากย์เสียงให้ฟังเป็นธรรมชาติ

  • เขียนเหมือนพูด ใช้ประโยคสั้น ๆ ภาษาพูด เสียงจะลื่นกว่าภาษาเขียนยาว ๆ
  • ใช้การขึ้นบรรทัดใหม่ แทนจุดหรือจุลภาค ระบบจะเว้นจังหวะให้ตรงนั้น
  • คำที่อ่านผิด ให้สะกดตามเสียงอ่าน เช่น พิมพ์ "ห้าสิบเปอร์เซ็นต์" แทน "50%" หรือ "ไลค์" แทน "like"
  • ความเร็ว 1.1–1.2 เท่า เหมาะกับคลิป TikTok และ Reels ที่คนดูชอบจังหวะเร็ว
  • ทำบทสนทนา ขึ้นต้นแต่ละบรรทัดด้วยชื่อตามด้วยเครื่องหมาย : เช่น แม่: กินข้าวยัง แล้วเลือกเสียงให้แต่ละคน

คำถามที่พบบ่อย

พากย์เสียงฟรีจริงไหม ต้องสมัครหรือเปล่า

ฟรีจริง ไม่ต้องสมัคร ไม่จำกัดตัวอักษร เพราะเว็บใช้ระบบเสียงพูดที่มีอยู่ในเบราว์เซอร์และเครื่องของคุณเอง ข้อความไม่ได้ถูกส่งไปเก็บที่เซิร์ฟเวอร์ของเรา

ทำไมไม่มีเสียงภาษาไทยให้เลือก

เสียงที่ใช้ได้ขึ้นกับเครื่องและเบราว์เซอร์

  • คอมพิวเตอร์: เปิดด้วย Microsoft Edge จะได้เสียงไทยแบบธรรมชาติ (Premwadee และ Niwat) ฟังดีที่สุด หรือใช้ Chrome จะมีเสียง Google ไทย
  • Android: ไปที่ การตั้งค่า › ระบบ › ภาษา › เอาต์พุตการอ่านออกเสียง เลือกบริการของ Google แล้วดาวน์โหลดเสียงภาษาไทย
  • iPhone/iPad: ไปที่ การตั้งค่า › การช่วยการเข้าถึง › เนื้อหาที่พูด › เสียง › ภาษาไทย แล้วดาวน์โหลดเสียง
เสียงไหนฟังเป็นธรรมชาติที่สุด

เสียงที่มีคำว่า Online (Natural) บน Microsoft Edge ฟังเป็นธรรมชาติที่สุด รองลงมาคือเสียง Google ไทยบน Chrome และ Android

เอาเสียงไปใส่คลิป TikTok หรือ CapCut ยังไง

บนคอมพิวเตอร์ Windows กดปุ่ม "บันทึกเป็นไฟล์" จะได้ไฟล์ .wav ไปลากใส่ CapCut ได้เลย บนมือถือใช้การอัดหน้าจอของเครื่องขณะเล่นเสียง แล้วใช้เมนูแยกเสียงใน CapCut

นำเสียงไปใช้ในงานที่มีรายได้ได้ไหม

เสียงมาจากระบบเสียงพูดของเบราว์เซอร์และระบบปฏิบัติการ ซึ่งแต่ละเจ้ามีเงื่อนไขการใช้งานของตัวเอง ถ้าจะใช้ในงานโฆษณาหรืองานรับจ้าง ควรตรวจสอบเงื่อนไขของผู้ให้บริการเสียงนั้น ๆ ก่อน

ข้อความที่พิมพ์ถูกเก็บไว้ไหม

ข้อความเก็บไว้ในเครื่องของคุณเท่านั้น เพื่อให้เปิดครั้งหน้าไม่หาย เราไม่ได้เก็บไว้ที่เซิร์ฟเวอร์ ลบได้โดยลบข้อความในกล่อง
